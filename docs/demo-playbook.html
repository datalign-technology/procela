Cold open · before you speak

Setup checklist

  1. Sign in as super‑admin. Open Settings.
  2. Click Load Tidewater demo. Confirm. Wait for the seeded banner.
  3. Sign out. Sign back in as Susan Chen.
  4. Land on the Dashboard.
Sanity check My Dashboard reads 3 open tasks, 1 open issue, Customer Data under My Domains. Overview strip shows non-zero counts for Value Streams, Data Assets, Systems. If not: reseed and start again.

The flow · nine beats

Run the demo

Every beat below is a checkpoint. The time on the left is what you should have spent by the end of it. If you're two minutes over, cut the next beat's detail, not its point.

01
30 secDashboard, signed in as Susan Chen

The persona is populated, not stubbed

Point at My Dashboard: three open tasks with real due dates, one HIGH severity issue, ownership of a domain. Contrast implicit: most catalogues open on zeros.

Say Every one of these numbers is real accountability against a real person.

02
2 minWorking in… Tidewater Electric → Processes

Wand for Electric, then Water — same code, different output

The cache is pre‑warmed: both wands return instantly. If you want the live path, hit Regenerate from AI.

Click the wand at Electric → hierarchy fills with SCADA, outage management, generation. Switch Working in to Water → wand again → treatment, distribution, wastewater.

Say Same code path, different active‑org context. This is what business‑first means — the platform speaks their operational language.

03
5 minOutage Management → Detect & Assess → Outage triage

An activity carries operational weight

Open the seeded Outage triage activity. Walk down the panel: Responsible Melissa Patel, systems SCADA + OMS, dependencies show a predecessor and a successor, Criticality Tier 1, RTO 4h, Success measure “Field crew on site within 30 min”.

Scroll to Inputs/Outputs. Mapped to Outage Logs and Customer Master.

Say When a regulator asks “what’s the RTO for outage triage?” — this is where the answer lives, not in a spreadsheet somebody has to go find.

04
3 minAsk AI · top bar

The Ask AI money moment

Open Ask AI. Click the starter prompt “Which data assets do we have that no process uses?”

Answer names Legacy Billing Extract and Meter CSV Dump with clickable inline citations, plus a green Orphan Assets → chip.

Say Every asset name is a link back to the row. The chip is a one‑click handoff to the page that solves the problem. No hallucination — if it’s in the answer, it’s in your catalog.

05
2 minSettings → Connectors · then Data Assets → Meter Reads

The edge agent — their network, our catalog

A seeded connector row is already ONLINE. Don’t try to install one on stage.

Show the Tidewater Data Platform Connector row: green ONLINE, agent v1.2.0, last heartbeat 45 seconds ago. Open the Events tab: PAIRED, SCAN_STARTED, SCAN_COMPLETED, ASSETS_REPORTED, HEARTBEAT.

Cross to Data Assets → Meter Reads. Point at the Synced 5 min ago chip — that came from the connector, not a human editor.

Say The agent runs inside your network. It sends metadata only — asset names, row counts, freshness timestamps. Never data content, never credentials. One‑way outbound HTTPS. If it stops calling home for four hours, you get a notification.

06
5 minSettings → Process & Asset Lifecycle

Change management with segregation of duties

Switch to Review mode. Back on the Catalog, demote an Active activity to Draft, edit the RTO, click the status pill: only option is Pending Review.

Type “Tightened RTO after Q3 incident review” and submit. Yellow banner shows submitter + comment.

Try to approve as the same user → blocked (“submitter cannot approve their own change”). Sign in as a different reviewer → approve.

Say This is your change control. The audit trail travels with the row.

07
2 minNew tab → /login?tenant=tidewater

Tenant white-label

Sign-in card reads Tidewater Utilities with the ⚡ glyph. Primary SSO button is teal, labelled “Sign in with Tidewater SSO”. Small Powered by Procela line.

Say Your prospects, your customers, your brand — not ours.

08
3 minData → Data Quality · then Governance → Tasks & Issues

DQ and issues tell one story

Two rules land: Customer Master email completeness at 96 (green), Generation Output write‑latency at 62 (red).

Cross to Governance → Issues: the seeded HIGH severity ownership issue is against Generation Output. Same asset.

Say When a rule fails, an issue opens and the responsible steward gets pinged. This one is already in flight.

09
CloseWherever you are — don’t navigate

Land the thesis

Return to Susan’s Dashboard if you drifted. Say what the ten prior minutes proved:

Every process step has an owner, every data asset has a domain, every dependency is declared, every governance decision is auditable. Not because we told a data steward to type it in — because the platform’s shape made it the path of least resistance.

Ask What would it take to get your catalog to look like this?
